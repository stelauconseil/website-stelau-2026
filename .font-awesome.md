# Font Awesome Configuration

Detected by the Font Awesome agent tools. Commit this file so the whole team benefits.

## Integration

- **Method:** Self-hosted Kit SVG assets rendered inline at Astro build time; no client-side Font Awesome runtime.
- **Version:** 7.3.1
- **License:** Pro+ (confirmed by Stelau; commercial license included in Kit export)
- **Kit ID:** 1daec18b88
- **Kit Revision:** 3
- **Families:** duotone
- **Source:** Official Font Awesome CLI, authenticated Kit API (Duotone Solid SVGs).

## Defaults

- **Style:** solid
- **Family:** duotone
- **Prefix:** fad

## Import Pattern

- Selected original SVGs are stored under src/assets/icons/fontawesome/duotone-solid/.
- Wrapper: import Icon from '@/components/Icon/Icon.astro'.
- Usage: <Icon name="users" size={24}/>. The size is the square canvas size in pixels.
- Only authoritative paths from the supplied Kit/API are used. Missing names fail the build rather than silently rendering an empty icon.

## Conventions

- Primary/secondary layers follow Stelau theme variables; both layers use the same Stelau blue; the secondary layer has 40% opacity, following the Font Awesome Duotone default. Optional per-icon --fa-secondary-color and --fa-secondary-opacity overrides remain supported.
- Icons next to text are decorative: aria-hidden="true", focusable="false".
- Existing Arrow, theme and navigation components retain their current conventions; decorative Duotone icons now cover Home, About, Expertise, Cases, Blog, Contact, Legal and 404 pages in FR/EN.
- No password or API token is stored in the project or the generated site.
- Icon provenance and Kit license are retained with the selected assets.
